# rememberanyth.ing

Remember any number (card, passport, phone, or pi) by chunking it, typing it back and reviewing it on a schedule. Dark, minimal, Monkeytype-style. Everything stays in the browser: no backend, no accounts, no network calls.

## Run

```sh
pnpm install
pnpm dev        # http://localhost:5173
pnpm test       # engine unit tests (Vitest)
pnpm e2e        # end-to-end tests (Playwright, builds + previews on :4173)
pnpm build      # static site in dist/
```

## How it works

- `src/engine/session.ts`: the learning loop as a pure reducer. Flash a chunk, type it, chain it with the previous ones, then a final full run. A wrong key restarts only the current chunk. Two misses in a row (or any miss in the final run) re-flash that chunk.
- `src/engine/chunk.ts`: input normalization and chunk presets (4-4-4-4, 3-3-4 for phones, the user's own grouping if they typed one).
- `src/engine/srs.ts`: review ladder of 1, 3, 7, 16, 35 and 90 days.
- `src/engine/hooks.ts` + `src/data/hooks.json`: static hook suggestions. **The hook table is a draft and needs a human review pass before launch.**
- `src/data/pi.ts`: 10,000 decimals, generated by `pnpm gen:pi`.
- `src/store/db.ts`: IndexedDB via idb-keyval, with an in-memory fallback.
- `src/ui/theme.css`: the Graphite design tokens.

## Deploy

Static hosting (Cloudflare Pages or Netlify read `public/_headers` for the CSP and security headers). Build command `pnpm build`, output `dist/`, custom domain `rememberanyth.ing`.
